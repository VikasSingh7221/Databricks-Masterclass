# Level 1 - Beginner Questions

## 1. What is Compute in Databricks?

Expected Answer

Compute is the collection of cloud resources (CPU, Memory, and Virtual Machines) used to process workloads such as notebooks, SQL queries, ETL pipelines, machine learning, and streaming jobs.

---

## 2. Why does Databricks separate Compute and Storage?

Expected Points

- Independent Scaling
- Better Performance
- Lower Cost
- Flexible Resource Allocation
- Multiple Compute Clusters can access the same data

---

## 3. What is a Cluster?

Expected Answer

A Cluster is a collection of Virtual Machines working together to execute Spark applications.

---

## 4. What is the Driver Node?

Expected Points

- Coordinates execution
- Creates DAG
- Creates Execution Plan
- Schedules Tasks
- Collects Results

---

## 5. Does the Driver process data?

Answer

No.

The Driver coordinates execution.

Workers process data.

---

## 6. What are Worker Nodes?

Expected Answer

Workers execute Spark Tasks and process data partitions.

---

## 7. What is an Executor?

Expected Answer

An Executor is a process running on a Worker Node responsible for executing Tasks.

---

## 8. What is a DAG?

Expected Answer

Directed Acyclic Graph.

Represents the execution plan generated by Spark.

---

## 9. What creates a Job?

Answer

An Action.

Examples

- show()
- count()
- collect()
- write()

---

## 10. What creates a Stage?

Answer

Shuffle Boundaries.

Examples

- join()
- groupBy()
- repartition()

---

## 12. Difference between Job, Stage and Task?

Expected Answer

Job

Created by Action

Stage

Created by Shuffle

Task

Processes a Partition

---

## 13. What determines the number of Tasks?

Expected Answer

The number of Partitions.

---

## 14. What happens if a Worker crashes?

Expected Answer

The Driver detects the failure and reschedules failed Tasks to another available Executor.

---

## 15. Explain fault tolerance in Spark.

Expected Points

- Task Retry
- Partition Recomputation
- Driver Coordination

---

## 16. Explain Compute Types.

Expected Discussion

- All-Purpose
- Job Compute
- SQL Warehouse
- Serverless

---

## 17. Explain Access Modes.

Expected Discussion

- Shared
- Single User
- Legacy

Explain how they differ from Unity Catalog.

---

## 18. What is Databricks Runtime?

Expected Answer

An optimized distribution of Apache Spark including Delta Lake, cloud optimizations, security enhancements, and additional libraries.

---

## 19. What is Photon?

Expected Answer

A native execution engine that accelerates supported SQL and DataFrame workloads without requiring code changes.

---

## 20. What is Runtime ML?

Expected Answer

A Databricks Runtime variant containing pre-installed machine learning libraries.

# Level 3 - Advanced Questions

## 21. Explain Autoscaling.

Expected Discussion

- Scale Up
- Scale Down
- Minimum Workers
- Maximum Workers

---

## 22. Difference between Autoscaling and Auto Termination?

Expected Answer

Autoscaling changes Worker count.

Auto Termination stops the entire Cluster.

---

## 23. What is an Instance Pool?

Expected Answer

A collection of pre-allocated Virtual Machines used to reduce Cluster startup time.

---

## 24. Difference between Instance Pool and Cluster?

Expected Answer

Instance Pool

Infrastructure

Cluster

Spark Compute

---

## 25. Difference between Photon and Databricks Runtime?

Expected Answer

Runtime

Complete Spark Environment

Photon

Execution Engine

---

# Tips for Interviews

When answering Compute questions:

✅ Start with the business problem.

✅ Explain the architecture.

✅ Mention trade-offs.

✅ Discuss scalability.

✅ Discuss cost.

✅ Discuss performance.

✅ Mention production best practices.

Interviewers look for **reasoning**, not just feature names.
